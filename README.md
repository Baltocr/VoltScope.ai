# VoltScope AI

VoltScope AI is a lightweight Streamlit-based electrochemistry analysis app designed to help researchers process, visualize, and interpret current-potential data. The initial MVP focuses on calculating the operational electrochemical stability window (ESW) from uploaded CSV files using a user-defined current-density threshold.

The app allows users to upload electrochemical datasets, select potential and current/current-density columns, normalize current by electrode area if needed, identify anodic and cathodic threshold-crossing potentials, calculate the resulting ESW, and generate a short interpretation of the results. This workflow is especially useful for comparing electrolyte stability across solvents, electrode materials, or experimental conditions.

The long-term goal of VoltScope AI is to become an AI-powered research assistant for electrochemistry, helping users move from raw data to clean figures, quantitative metrics, mechanistic interpretation, and poster/paper-ready scientific communication.
